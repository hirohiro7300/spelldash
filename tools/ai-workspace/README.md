# AI作業場（ChatGPT × Claude × Muse）

ChatGPT・Claude・Muse（Meta）を1つの会話でつないで、答えを見比べたり、話し合わせたり、作業をリレーで仕上げさせたりする作業場です。
`index.html` を1つ開くだけで動きます（サーバーもインストールも不要）。

> SpellDash 本体とは別の道具です。`.vercelignore` で配信から外しているので、spelldash.net には出ません。

## できること

| 進め方 | 動き | 向いていること |
|---|---|---|
| みんなに聞く | 同じ質問に全員が同時に、別々に答える（横に並べて表示） | 答えを見比べる |
| 話し合う | 順番に、前の人の発言を読んでから意見を言う（1〜3周。あとから「もう1周」も可） | 考えを深める・議論 |
| リレー | 前の人の成果物を引き継いで改善し、最後の人が完成版にする | 文章・企画を仕上げる |

- **まとめる**: 選んだAIが、会話全体を「結論／合意した点／意見が分かれた点／次にやること」に整理します。
- **@名前で指名**: `@Claude これをレビューして` のように書くと、その人だけが答えます。
- **メンバーの設定**: 役割（「発想担当」など）・モデル・色・話す順番を変えられます。OpenRouter にあるモデルなら、Gemini などを4人目として足すこともできます。
- **記録**: 会議はこのブラウザに最大60件保存。「書き出し」で Markdown ファイルにできます。1件ごとのトークン数と料金も出ます。

## はじめかた（5分）

1. この `index.html` をパソコンに保存して、ダブルクリックで開く（Chrome か Edge がおすすめ）
2. [OpenRouter](https://openrouter.ai/) でアカウントを作り、[Credits](https://openrouter.ai/settings/credits) でクレジットを買う（前払い制）
3. [Keys](https://openrouter.ai/settings/keys) でキーを作る
4. 作業場の「設定」→「OpenRouter のキー」に貼り、「接続テスト」で3人とも ✓ になるのを確かめて「保存して閉じる」
5. 下の入力欄に相談を書き、進め方を選んで送信（Ctrl+Enter でも送れます）

OpenRouter のキー1つで、OpenAI（ChatGPT と同じ GPT 系のモデル）・Anthropic（Claude）・Meta（Muse）の3社のモデルを呼べます。
各社のキーを直接使うこともできます（設定の「各社のキーを直接使う（上級者向け）」と、各メンバーの「接続先」）。Meta の API は地域によってまだ使えないことがあるので、Muse は OpenRouter 経由がおすすめです。

## 料金について

- **ChatGPT Plus や Claude Pro などの月額プランでは使えません。** API は別料金で、使った分だけかかります。
- 初期設定（標準）のモデルと料金の目安（100万トークンあたり。2026年11月時点の OpenRouter の表示）:

  | メンバー | モデル | 入力 | 出力 |
  |---|---|---|---|
  | ChatGPT | `openai/gpt-6.2-sol` | $2.00 | $10.00 |
  | Claude | `anthropic/claude-opus-5.5` | $4.00 | $20.00 |
  | Muse | `meta/muse-spark-1.3` | $1.25 | $4.25 |

- 設定の「最高性能」（GPT-6.2 Astra・Claude Fable 5.2・Muse Wonder）は賢いぶん高く、「節約」（GPT-6.1 Terra・Claude Haiku 5.5・Muse Ember）はずっと安くなります。
- 話し合いでは、毎回それまでの会話全体を各AIに送るので、会話が長くなるほど1回の料金が上がります。話題が変わったら「新しい会議」を始めるのが節約のコツです。
- 1件ごとの料金はカードの下に、会議の合計は上の帯に出ます（OpenRouter 経由のときだけ）。

## 安全について

- APIキーと会話は、このブラウザの保存領域（localStorage）にだけ置かれます。送り先は各AIの会社（または OpenRouter）だけです。
- 共用のパソコンでは、設定の「このブラウザにキーを記憶する」をオフにしてください（タブを閉じると消えます）。
- AIの返事は安全な形で表示します（返事の中の HTML やスクリプトは動きません）。ページ自体も CSP で、決まったスクリプト以外は動かないようにしています。

## 困ったとき

| 表示 | すること |
|---|---|
| APIキーが正しくないようです | キーの貼り間違い（前後の空白など）を確かめる |
| 残高（クレジット）が足りません | OpenRouter でクレジットを足す |
| モデル「…」が見つかりません | 設定のモデル名を確かめる（入力欄に OpenRouter の一覧から候補が出ます） |
| 通信できませんでした | ネット接続や、広告ブロックなどの拡張機能を確かめる |

## ファイル

- `index.html` … 本体（HTML・CSS・JavaScript がこの1つに入っています。外部のライブラリは使っていません）
- `update-csp.mjs` … `index.html` の `<script>` を書き換えたら、`node tools/ai-workspace/update-csp.mjs` を実行してください。ページの安全設定（CSP）にあるスクリプトの指紋（sha256）を入れ直します。これをしないと、ブラウザがスクリプトを止めてページが動きません。
