# 4D Branch

**未来の分岐を、プロジェクトをまたいで描くメモ帳。**
目標・行動・分岐・結果をノードとして記録し、相互につないで未来の分岐を見える化します。
一般的なフローチャートと違い、**異なるプロジェクトの分岐が交差・合流し、相互に影響する**様子を 1 枚に描けます
（例:「広告運用を学ぶ」が、仕事の成果・SpellDash の集客・独立の 3 つの目標に同時に効く）。

AI による分析や予測はしません。外部の AI と対話して考えた内容を、自由に記録するための道具です。

> SpellDash とは別の独立したプロジェクトです（コード・設定・データを共有しません）。
> このリポジトリの `4d-branch/` に置いていますが、独自の `package.json`・テスト・CI・デプロイ設定を持ち、
> SpellDash の配信（`.vercelignore`）からも外しています。

## 動かし方

```bash
cd 4d-branch
npm install
npm run dev
```

ブラウザで http://localhost:5178 を開きます。初回はデモ（3 つのプロジェクト）とようこそ画面が出ます。

メニュー（右上の ⋯）の「やりたいことリスト（2,000）を読み込む…」で、**やりたいこと 2,000 件の地図**を読み込めます。
仕事（SpellDash・FC マーケティング・独立）から、学び・お金・健康・旅・暮らし・人・趣味・社会・内面まで 12 の領域・101 のテーマに分け、
「先にやること」の道筋と、「どちらを選ぶか」の分岐（仕事の道筋に関わるものはシナリオに結ぶ）、領域をまたぐつながりを付けています。
横は時間の見通し（左 = 今すぐ、右 = いつか。期限は読み込んだ日から数える）、縦は領域ごとの帯です。
同じ中身を読みやすい一覧にしたものが [docs/wishlist/](docs/wishlist/README.md) にあります（`node scripts/wishlist-md.mjs` でデータから作り直せます）。

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバー |
| `npm run build` | 型チェック → `dist/` に静的ファイルを出力 |
| `npm run preview` | ビルドした物を本番と同じセキュリティヘッダーで確かめる（http://localhost:4178） |
| `npm test` | 単体テスト（Vitest） |
| `npm run e2e` | ブラウザでの通しのテスト（Playwright。先に `npm run build`） |
| `npm run build:artifact` | claude.ai の Artifact 用の 1 枚のページ（`artifact/4d-branch.html`） |
| `npm run e2e:artifact` | Artifact 版の通しのテスト（偽の `window.claude` で同期・書き出し・スマホの幅） |
| `npm run check` | 上の全部 |

E2E は `vite preview` を自分で立ち上げます。ブラウザが無ければ `npx playwright-core install chromium` で入れてください。

## 画面

| 場所 | できること |
| --- | --- |
| 上部 | マップ／リストの切替・表示の設定・検索（`#タグ` も可）・ノードの追加（目標／行動／分岐／結果）・元に戻す／やり直し・保存の状態・メニュー |
| 左 | プロジェクト一覧（押すと強調、⌘／Ctrl クリックで複数）・シナリオ一覧・タグ・保存先 |
| 中央 | 無限キャンバス（拡大縮小・移動・選択・接続・分岐・合流・折りたたみ）、ミニマップ |
| 右 | 選んだノードの文章・期限・条件・タグ・所属プロジェクト・シナリオ・つながり／接続線の関係・条件 |
| 下部 | 時間軸（押した日までを表示・▶ で未来へ再生）とシナリオ切替 |

主な操作:

- **作る**: 空いている所をダブルクリック／上の ＋目標 など／`N`
- **つなぐ**: ノード右の ● を別のノードへドラッグ（複数選択中は全部から）
- **分岐**: ● を何もない所で離して種類を選ぶ／`Tab`／詳細の「2 つに分岐」
- **合流**: ⇧クリックで複数選び「合流ノードを作る」
- **折りたたみ**: ノード右下の印・`C`／接続線は詳細の「この線の先を折りたたむ」
- **移動・拡大縮小**: ドラッグ・2 本指スクロール／ピンチ・⌘（Ctrl）＋スクロール（表示メニューでホイール＝ズームにも切替可）
- **元に戻す／やり直す**: ⌘Z ／ ⇧⌘Z（Ctrl+Z ／ Ctrl+Y）

すべてのショートカットは画面右上の `?` から見られます。

## データの守り方

- 変更はすぐこのブラウザ（IndexedDB）に自動保存。閉じる瞬間の変更は緊急コピー（localStorage）で守り、次の起動で新しい方を採ります。Artifact 版では、サインインしていればアカウントにも写しを置きます。
- 保存のたびに版番号を確かめ、別の場所の書き込みを黙って上書きしません（重なった内容はバックアップへ退避）。
- 同じブラウザでタブを 2 つ以上開くと、編集できるのは 1 つだけ（ほかは閲覧のみ・引き継ぎ可）。
- バックアップ: 10 分ごと（変更がある間）・毎日・取り込みや復元の直前に自動。メニュー →「バックアップと復元」から戻せます。
- JSON でいつでも書き出し・読み込み（置き換え／追加）。**ブラウザのデータを消すと消えるので、大事なときは書き出して別の場所にも残してください。**
- `?stress=2000`（Artifact 版は `#stress-2000`）は保存しない性能確認用の一時表示で、ふだんのデータには触れません。

## 構成

```
4d-branch/
├── docs/DESIGN.md        技術構成・データモデル・画面設計・実装順序
├── docs/wishlist/        やりたいことリスト 2,000 件の読みやすい一覧（データから作る）
├── scripts/              Artifact 版の 1 枚のページ・やりたいことリストの一覧を作る
├── src/
│   ├── model/            データの形・検証と移行・派生データ・折りたたみ・検索・配置
│   ├── store/            ストア（トランザクション）と編集履歴（Undo/Redo）
│   ├── persist/          保存（IndexedDB・緊急コピー・タブのロック・バックアップ）と JSON の入出力
│   ├── canvas/           キャンバスの描画・当たり判定・操作・ミニマップ・その場の編集
│   ├── ui/               上部・左右・下部・リスト・ダイアログ・操作ガイド
│   ├── app/              画面の組み立て・操作（commands）・見え方の状態と計算
│   └── demo/             デモ（3 プロジェクト）・やりたいことリスト（2,000 件のデータと組み立て）・性能確認用の大きなグラフ
└── tests/
    ├── unit/             Vitest
    └── e2e/run.mjs       Playwright
```

実行時に読み込む外部のライブラリはありません（ビルドに Vite と TypeScript を使うだけ）。

## claude.ai の Artifact 版

`npm run build:artifact` で `artifact/4d-branch.html`（CSS と JS を埋め込んだ 1 枚。公開のときに claude.ai が骨組みで包む）を作り、
claude.ai の Artifact として公開しています。Artifact の中では次が変わります（同じコードが、動いている場所を見て切り替える）。

- **アカウントへの同期**: サインインしていれば、あなただけが読める場所（この Artifact の db の `data/users/<id>/`）にも写しを置き、別の端末でも同じ内容が出ます。手元（IndexedDB）が主のままで、重なったときはどちらの内容もバックアップに残します（[docs/DESIGN.md](docs/DESIGN.md) §5.1）
  - 新しい端末では、何もしていないデモの代わりにアカウントの内容を読み込みます。このブラウザにもアカウントにも別々の内容があるときは「どちらの内容を使いますか？」と聞き、決めるまで送りません（使わなかった方もバックアップへ）
  - 止まった同期は、メニュー →「バックアップと復元」の「同期をやり直す」で再開できます
  - このブラウザでバックアップを作れない（IndexedDB が使えない）ときは、置き換えられる内容を JSON で書き出し、保存できたときだけ続けます
- **書き出し**: `downloads` 機能で保存を頼みます（使えない画面ではコピーできるダイアログ）
- **性能確認**: `#stress-2000`（新しいタブは開けないので同じ画面のまま切り替え、上の帯の「ふだんの画面へ」で戻る）

`npm run e2e:artifact` は、公開と同じ骨組みと偽の `window.claude`（db・user・downloads）で、同期・別の端末・初めての同期の聞き方・書き出し・スマホの幅を確かめます。

## デプロイ

`dist/` の静的ファイルだけで動きます（サーバー不要）。Vercel なら、このリポジトリを**別のプロジェクト**として取り込み、
**Root Directory を `4d-branch`** にします（`vercel.json` にビルドの設定とセキュリティヘッダーがあります）。

別のリポジトリに切り出すときは:

```bash
git subtree split --prefix=4d-branch -b 4d-branch-only
```

CI は `.github/workflows/4d-branch.yml`（`4d-branch/` を変えたときだけ動く）。切り出すときは `4d-branch/.github/workflows/` へ移し、`working-directory` を外してください。
