# 「月額1,000円払ってもやりたい」SpellDash — 価値設計（2026-09-06）

> 創業者依頼「プレイヤー目線で月額1,000円の価値がある設計をし、実装まで自走」への回答。
> **決済は実装しない**（v4 §9 / v4.1 §2 維持）。ここで作るのは「払う価値のある体験」。通貨・ガチャ・ショップ・Pay to Winは作らない。

## 1. 1,000円の根拠 — 人が払う理由は4つに集約される

競合の価格帯（Duolingo Super ≈1,100円/月、mikan PRO ≈1,000円/月）で人が払うのは「機能の数」ではなく次の4つ。

| # | 払う理由 | 一言で | SpellDashでの実装 |
|---|---|---|---|
| 1 | **決めてくれて、5分で終わる** | 意思決定コストゼロ＋完了感 | **今日のセット**（Batch A） |
| 2 | **前進の証拠** | 覚えた数が増え、忘れていないことが数字で分かる | 覚えた単語カード／カテゴリ別進捗／**週間レポート**／**覚えた単語の推移**／思い出せた率（Batch D） |
| 3 | **自分専用** | 自分の仕事・試験の単語を入れられる | **マイ単語帳**（Batch C） |
| 4 | **気持ちいい** | 手触り・儀式・伴走者 | Challengeの即時進行・カード内スコア・コンボ段階（Batch B）／はちゃんの完了・週次セリフ |

無料の英単語アプリは「無限に問題が出る」ところで止まる。1,000円払うアプリは「今日のぶんが終わり、来週の自分が前より賢いと分かる」。SpellDashはその状態を目指す。

## 2. 実装した体験（2026-09-05〜06、PR #43〜#46）

- **今日のセット**: 復習期日・苦手・新語を混ぜたN語（10/15/25）を自力で思い出せたら「今日のぶん完了」。ホームCTA→進捗バー→完了パネル（明日の復習予定まで）→7日ドット
- **Challengeの手触り**: 単語間の待ち時間ゼロ、カード内スコア/コンボ常設、5/10/20コンボの段階演出、ベストまでの差分
- **マイ単語帳**: 1語ずつ／まとめて貼り付けで登録、同じ仕組みで出題・復習、状態バッジ
- **成長の証拠**: 覚えた単語「今週 +N」、30日推移グラフ、週間レポート（学習日数・覚えた・思い出せた率・ベスト、はちゃんの一言、画像シェア）。思い出せた率は「1日以上前に覚えた語を復習で思い出せた割合」

## 3. 将来の課金線引き案（実装しない・案として保存）

原則: **学習に効く基本機能は全部無料**。Proは「愛着・表現・余裕」に対して払う。

| 無料（学習の本体） | Pro候補（1,000円/月の中身） |
|---|---|
| Study／Challenge／Daily／Battle 全モード | マイ単語帳の上限解放（無料 100語 → Pro 無制限）＋端末間同期 |
| 今日のセット・復習・Recall Loop | 週間レポートの画像シェア・月間レポート・PDF |
| 覚えた単語・カテゴリ別進捗・30日推移 | 90日〜1年の推移、定着率の詳細 |
| はちゃんPhase1（3場面の応援） | はちゃんの表情差分・季節の一言・結果画面の演出 |
| ライト/ダークテーマ | 追加テーマ・ホーム背景 |

Pay to Win禁止: 覚えやすくなる・判定が有利・ランキング有利・復習回数増は課金対象にしない（v4.1 §2）。

## 4. 解禁条件（変更なし）

v4 §9: 累計100人・継続20人・週3回利用10人・「有料でも使いたい」5件 → まず**有料プランのユーザーインタビュー**。¥1,000は仮説として保持。

## 5. 次に測ること（定性のまま）

- 「今日のセット」を押した人が完了までいくか（完了パネル到達）
- 翌日CTAが「完了」から「始める」に戻った時にもう一度押すか
- マイ単語帳に何語入れるか（0語で止まるなら入口の問題）
- 週間レポートをシェアするか／「思い出せた率」の数字に反応するか
