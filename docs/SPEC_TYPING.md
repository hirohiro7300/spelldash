## 3. キー

document の keydown で受ける（焦点が `#input` に無くても打てる。画面キーボードの合成イベントも上がってくる）。キーは英単語も日本語も `romajiKeyOf(event)`（IME オンの `Process`・JIS かな配列・Shift つきも物理キーの位置で読む）。下の表は英単語・日本語（1 分）。長文は §9.3。

| キー | ready | running | result | loading・error |
|---|---|---|---|---|
| ローマ字のキー（a-z・0-9・`-`・`'`） | 時間を測り始め、そのキーを判定 | 判定（正しい／ミス／飲む） | 何もしない | 何もしない |
| ほかの 1 文字のキー（`/` など） | 既定 | 数えない・`preventDefault` | 既定 | 既定 |
| Backspace・Delete | `preventDefault` だけ | 同左 | 何もしない | 何もしない |
| Esc | 何もしない | ready に戻す（長文は §9.3: そこまでの結果） | もう一度 | 何もしない |
| Enter・Space | 時間を測り始める（判定しない） | 数えない | 0.6 秒以降なら もう一度 | 何もしない |
| Enter・Space（焦点がボタン・リンク） | 既定（押す） | 既定。ただし種類のタブ・「ご意見・不具合」の上では押させない | 既定 | 既定 |
| IME 確定の Enter（`isComposing`・`keyCode 229`）・押しっぱなし（`repeat`）・修飾キーつき | 数えない（修飾キーつきは既定のまま） | 同左 | 同左 | 同左 |

- 扱わない場所: 開いている窓（js/typingKeys.js `modalOpen`。読み上げの行き先と同じ js/srLive.js `openWindow` を `#input` から見る: ご意見の窓〔aria-modal・背後は inert〕と `<dialog>.showModal()` の窓。PR #168 のレビュー 7）、対象が `#input` 以外の入力できる要素。
- 語末の ん を手本どおり n 1 つで終えたあと、nn と打つ癖の 2 つ目の n: 次の語の 1 打目として通るならそちらを先に取り、通らず 0.6 秒以内で終えた語の続きとして通るなら飲む（数えない）。**Study と順番が違う**（Study は続きの窓の中では続きが先）: 手本が語末の ん を n 1 つで見せるので、手本どおりに打つ人の次のキーを飲まないため。nn の人が損をするのは次の語が な行 で始まるときの 1 ミスだけ。

## 4. 数え方

| 名前 | 定義 |
|---|---|
| 正しい打鍵 `correct` | 判定で通ったキーの数（飲んだ続き・無視したキーは入れない） |
| ミス `miss` | 判定で通らなかったローマ字のキーの数 |
| **打/分** | `Math.round(correct × 60 ÷ 秒)`（60 秒なら correct と同じ。「打った文字数」と 1 つにまとめた。WPM という名前は使わない） |
| **正確さ** | `total > 0 ? Math.floor(correct × 100 ÷ total) : null`（切り捨て: ミスがあれば 100% にしない。null は「―」） |
| 間違えたキー | ミスのとき「打つはずだったキー」ごとの回数。多い順・同数は a→z・上位 3。`spelldash_key_miss` には書かない |

- 日本語の打/分はローマ字のキーで数える（shi は 3、si は 2）。Challenge の 打/秒（かなの数）とは定義が違うので並べない・混ぜない。
- 時間は `?t=N`（1〜60 の整数。ほかは 60）で縮められる（E2E 用。表示も「N秒」）。
- 自己ベスト: `localStorage.spelldash_typing_practice` = `{ v: 1, best: { en: { "60": { kpm, acc, day } }, ja: { … }, long: { "ja-s01": { … } } } }`（`long` は長文の文章ごと: §9.6）。**種類ごと・秒数ごと**（`?t=3` の 3 秒の回が 1 分の記録を壊さない）。比べるのは kpm だけ（はじめて／更新（前 N）／同じ／自己ベスト N（あと 差））。書く直前に読み直し、`best[kind][秒数]` だけ差し替える。最後まで打った回だけ保存。読めない・書けない端末では出さない。保存値の kpm が整数でない・0〜2000（`BEST_KPM_MAX`）の外なら壊れた値として無い扱い（次の結果が「はじめての記録」で上書きする）。
- 書いてよいキーは `spelldash_typing_practice`・種類の記憶 `spelldash_typing_kind`（タブを押したとき。Batch 65）と計測（`spelldash_device_id`・`spelldash_funnel_*`）、共通のフッターの `spelldash_billing_open` だけ（E2E が見る）。storage.js・stats.js・summary.js・ui.js・game.js・wordStore.js は import しない。

### 9.4 時計と数え方

- 時計（js/typingLong.js `createLongClock`）は止めていた間の合計で持つ: `firstAt`（最初に判定したキー。飲んだキーは入れない）・`lastAt`（最後に判定したキー）・`pausedMs`（止めた時刻から続きのキー（Space・Enter も）の時刻まで）・`pausedAtLast`（判定したキーを数えるたびに `pausedMs` を写す）。**時間 = `lastAt − firstAt − pausedAtLast`**。完走は最後の正しいキーまで、途中までは最後に判定したキーまで（Esc を押した時刻ではない）。止めた後に判定せずに Esc でも負にならない。Space／Enter で始めた回も、時計は最初に判定したキーから（反応の時間を入れない）。キーの時刻は受けた時刻（`performance.now()`）。
- Esc・やめるの 5 秒（`LONG_PARTIAL_MIN_MS`）はこの出す時間で見る（3 打を 0.3 秒で打って 5 秒待った回を 打/分 600 で出さない）。

| 名前 | 定義 |
|---|---|
| 正しい打鍵・ミス | 今と同じ。日本語の句読点は 1 打。英語の空白・記号・大文字は 1 打（Shift は数えない） |
| 時間 | 秒の切り捨てで「1分48秒」、60 秒未満は「48秒」、分があるとき秒は 2 桁（「1分02秒」）、ちょうどの分は「2分」 |
| 打/分 | `Math.round(correct × 60 ÷ 秒)`（今の `summarize` に小数の秒を渡す）。秒が 1 未満なら「―」 |
| 正確さ | `Math.floor(correct × 100 ÷ (correct + miss))`（今と同じ。0 打は「―」） |
| **スコア** | `Math.round((correct × 60 ÷ 秒) × (correct ÷ (correct + miss))²)`（丸める前の打/分 × 丸める前の正確さの 2 乗）。秒が 1 未満・0 打は「―」 |
| 間違えたキー | 今と同じ（上位 3）。英字は小文字、英語の空白は「空白」、日本語の句読点は「、」「。」と表示 |
| 長さの目安 | 行の数（select の項目と「残り N行」）。速さを仮定した所要時間は出さない（打つ速さは人で 2〜3 倍違う） |

- **スコアの考え方**: 速さと正確さを 1 つの数で言うため、正確さを重く見る。押したキー全部の速さに正確さの 3 乗を掛けた値と同じで、この打/分は正しいキーだけを数えるので「打/分×正確さの 2 乗」になる。ミスが無ければスコアは打/分と同じ。ミスが 1% 増えるとおよそ 3% 下がる。例: 正しい 450・ミス 12・120 秒 → 打/分 225、正確さ 97%、スコア 213。
- レベル・段階の名前は出さない（段階の名前と境目の表はよく知られたタイピングサイト独自のもので、名前を替えても表の写しになる）。日本語の打/分・スコアはローマ字のキーで数える。検定の級・「10分で N 字」には読み替えない。
- 結果の行: 柱（`#typingKind`）「北風と太陽・1分48秒」／途中まで「北風と太陽・途中まで 5／12行・1分02秒」、主の数（`#typingKpmLine`）「スコア 213」（ラベル `#typingKpmPre` が先。長文では単位「打/分」を隠す）、補足 1「打/分 225 ・ 正確さ 97% ・ ミス 12」＋自己ベストの句（名前と数の組は折らず区切りでだけ折る `.tp-pair`）、補足 2「間違えたキー s 3 空白 2 t 1」（ミス 0 なら出さない）、ボタン「もう一度（Enter）」→「次の文」（390 は 2 等分・44px、≥720 は中身の幅。`.tp-result__btns`）、本体への文（日本語の長文は「英単語も、打って覚える。日本語の訳だけを見て思い出して打つ。1日5分から。」、英語の長文は英単語と同じ文）。結果は最後のキー（か Esc・やめる）の直後に出るので、札が伸びても CLS に入らない。0.6 秒の守り・PC の焦点・盤面の畳み方は今と同じ。
