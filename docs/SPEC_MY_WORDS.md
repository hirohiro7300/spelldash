# マイ単語帳（Batch 79・81）

創業者の決定（2026-11-03）: 自分で作る単語帳はあってよい。入口はホームの 2 つ目のボタン（「英単語を学ぶ」の下）。ナビは今の 4 つのまま。熟語・大文字も入れる。打つときは大文字小文字を区別しない。数え方はマイ単語帳の中だけの別枠の 3 状態で、公開の 2,858 語の数とランクには混ぜない。同期は user_items の表があれば効き、無くても端末の中で動く（SQL はこちらから流さない）。

## 1. 入口と画面

- ホーム: 「英単語を学ぶ」の下に「マイ単語帳」（`/mywords.html`。同じ板の形で、朱の塗りをしない控えめな方）。ナビは「ホーム・英単語を学ぶ・学習状況・設定」のまま。
- 学習状況: 公開の語の数・3 つの札・目安の下に、線で区切った 1 行「マイ単語帳 N語・覚えた M」（マイ単語帳へのリンク）。2,858 語の数とランクとは別の行。
- マイ単語帳の画面（`mywords.html`。ヘッダー・ナビ・フッターはほかのページと同じ。noindex・sitemap に載せない）:
  - 数（N語・これから・あやふや・覚えた）と「学ぶ」（`/?learn=my`。語が無いときは出さない）
  - 語が無いときは 1 行「英語と日本語訳を入れると、ここで打って覚えられる。」
  - 1 語ずつ足す（英語・日本語訳）／まとめて足す（1 行に「english, 訳」。タブ区切り・全角の読点も可。区切りが無ければ英語と日本語の境で分ける）
  - 一覧（新しく足した語が上）: 英語・訳・状態（これから・あやふや・覚えた）・「消す」（確かめる窓のあとで消す）
  - 上限: 無料 100 語・Pro 1,000 語。上限で「足す」を止めて上限の文（Pro の話は `js/proFunnel.js canOfferPro` が許すときだけ）。見る・消すはできる
- 古い URL: `/list.html#myWords`（手元・アプリは単語帳のページの守り、配信は転送の `/?from=old#myWords`）はマイ単語帳の画面へ（ホームの 1 行は出さない）。ほかの古い URL の決まりは前のまま（`js/focus.js`）。
- 新しいページにしたわけ: 単語帳（`list.html`）は分野パック・場面カード・テキストから作る・ジャンルの一覧などを持つ大きなページで、旗の間はページの入口で全部止めている。この 1 つの面だけを開けると、止めた面が混ざる危険があり、検査も大きくなる。新しい小さなページは、守りを変えずに要るものだけを出せる。

## 2. 入れられる英語と打ち方

- 使える字: 英字・数字・ハイフン・アポストロフィ・空白（語の間に 1 つ。続いた空白は 1 つにする）。英字を 1 つ以上。150 字まで（Batch 81。前は 40 字）。全角の英数字は半角に、’ は ' にそろえる。訳も 150 字まで（前は 40 字）。1 語ずつ・まとめて とも同じ確かめ。
- 保存の鍵は小文字（`en`）。大文字を含む形は画面の形（`text`）として残す（KPI → 鍵 `kpi`・画面 KPI）。カードの id は `my-<鍵>`（前からの語の id は変わらない）。同じ鍵の語は 2 度足さない（全部の単語帳で 1 つ。§7）。
- 英小文字だけの 40 字までの語（KPI も含む）は 1 字ずつ判定（画面キーボードの a〜z で打てる。大文字は小文字で打てばよい）。41 字以上の英字だけの語は全文入力（Batch 81。前からの語は 40 字までなので打ち方は変わらない）。
- 空白・ハイフン・アポストロフィ・数字を含む語は全文入力（Enter で判定。`js/judge.js normalizeAnswer`: 大文字小文字・空白・ハイフン・アポストロフィを見ない。due diligence は「due diligence」「duediligence」どちらも正解）。画面キーボードにはハイフン・数字・アポストロフィが無く、端末のかな入力の道でもハイフンは落ちるので、ハイフンの語（e-mail）も全文入力にする（カードの `free` の印）。全文入力の語は端末のキーボードで打つ。
- 前からの語（英小文字とハイフン）・前の単語帳で作った場面カードはそのまま読める。場面カードは一覧に出して消せるが、学ぶ回と 3 状態の数には入れない。

## 3. 3 状態（マイ単語帳だけ）

- 決まりは公開の語と同じ（`js/learnState.js applyLearnAnswer`）: これから + 自力正解 → 覚えた、× → あやふや。あやふや + 自力正解は別の日に 2 回で 覚えた。覚えた + × → あやふや。× は 1 打ミス・ヒント・答え表示（全文入力の違う答えも）。
- 置き場: マイ単語帳の語そのもの（`spelldash_my_words` の要素の `ls`・`lsd`・`lsAt`）。目安の印 `lsf` は付けない。
  - 語の記録（`spelldash_word_stats`）には状態の欄を書かない: 公開の語の 3 状態・和 2,858・6 つの数・ランク・最高到達ランク・目安は公開の語だけから数えるので、マイ単語帳の答えで動かない（検査 78.2「非公開の語は欄なし」・`scripts/test-learn-state.mjs`・79.1）。
  - 送る 15 列は変えない。語と一緒に同期の項目 `user_items` の `my_word`（payload は語の全体）に乗るので、表があれば 3 状態もほかの端末へ届く（新しい方が勝つ）。
- 学ぶ回の答えの記録（回答の履歴・正誤の数）は、前のマイ単語帳と同じく `my-<鍵>` の id で語の記録に残る（公開の語の id には書かない）。学習状況の最初の画面の数には入らない。

## 4. 学ぶ回（`/?learn=my`）

- 中心の学習と同じ画面・打ち方（`js/game.js` の学ぶ回。柱は「マイ単語帳」）。列は これから（足した順）→ あやふや → 覚えた（最後に答えた時刻の古い順）。1 回 10 語。
- 回の終わり: 「N語 終わり」・今回 覚えた／あやふや・「マイ単語帳 覚えた M / N」・「続けて学ぶ」（まだ語があるとき）・「マイ単語帳へ」。ランクの幕・公開の語の数は出さない。回の続き（`spelldash_learn_session`）は使わない（中心の学習の続きを上書きしない）。
- 学んだ日・XP は中心の学習と同じく黙って数える（ランクと 3 状態の数には使わない）。

## 5. 人ごとの領域・バックアップ・同期

- `spelldash_my_words` は人の記録の鍵（`js/areaGuard.js` の端末の鍵の一覧に無い鍵はみな人ごと）。ゲスト → A の「はい」で移り、A と B は別々、バックアップの書き出しと読み込みに入り、開き直しても残る。新しい鍵は足していない。
- 同期は前のまま（`js/userItemsSync.js`・`docs/SQL_USER_ITEMS.md`）。表が無い・ログインしていないときは端末の中だけで動く。

## 7. 複数の単語帳（Batch 81。創業者の決定 2026-11-05）

- 単語帳を何冊も持てる（例: 仕事・旅行）。上限 20 冊。名前は 20 字まで・同じ名前は 2 つ作らない。
- 一覧は人ごとの鍵 `spelldash_my_books`（`[{ id, name }]` の並び。先頭が最初の単語帳）。保存が無い人は最初の単語帳「マイ単語帳」（id `main`）だけ。読むだけでは書かない。
  - 人ごとの領域（端末の鍵の一覧に無い鍵はみな人ごと: `js/areaGuard.js`）・ゲスト → A の「はい」で移る・A と B は別々・バックアップの書き出しと読み込みに入る（`spelldash_my_words`・`spelldash_slang` と同じ確かめ方: 単体 test-areas U1 と E2E 81.1）。
  - 同期はしない（端末の中だけ）。読めない値（壊れた JSON・配列でない・使える単語帳が 0）は上書きしない: 最初の単語帳で見せ、作る・名前を変える・消すは断る。
- 語は入っている単語帳の id を `book` に持つ。`book` の無い前からの語と、知らない id の語（ほかの端末で作った単語帳の語）は、最初の単語帳の語として読む（書き直さない: 前からの語・状態・語の記録はそのまま）。
  - `book` は同期の項目 `my_word` の payload（語の全体）に乗る。新しい種類・SQL は足さない。単語帳の名前は届かないので、ほかの端末ではその語は最初の単語帳に出る。
- 英語は全部の単語帳で 1 つ（カードの id `my-<鍵>` と 3 状態が変わらないように）。ほかの単語帳にある英語を足すと「「KPI」は「マイ単語帳」にすでに登録されています」。上限（無料 100 語・Pro 1,000 語）は全部の単語帳の合計。
- 単語帳を消すと、その単語帳の語も消える（確かめる窓で名前と語の数を言う）。最後の 1 冊は消せない（ボタンを出さない）。最初の単語帳を消すと、残った先頭の単語帳が最初の単語帳になる。

## 8. 画面（Batch 81）

- 1 語ずつ・まとめて足す は今の単語帳へ（「足す先は「仕事」。」）。一覧は今の単語帳の語。
- まとめて消す・移す: 「選ぶ」で行ごとの印・すべて選ぶ（今の単語帳の語）・選んだ数。「選んだ N 語を消す」は確かめる窓 1 つ（数を言う）で、語の保存は 1 回で書く（同期の印も 1 回: `js/userItemsSync.js touchItems`）。「選んだ語を移す」は移す先を選んで 1 回で書く（3 状態・足した時刻は残す）。単語帳を替えると選ぶは終わる。
- 訳の書き直し: 行の「直す」でその場の欄（Enter で保存・Escape でやめる・焦点は「直す」に戻る）。英語・3 状態・足した時刻・単語帳はそのまま。英語を変えるのは消して足し直す。
