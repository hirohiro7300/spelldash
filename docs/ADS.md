# SpellDash 広告クリエイティブ集

```
Status: DRAFT
Purpose: App Store公開前の広告クリエイティブ検証
Paid Ads: App Store公開まで本格出稿しない
Primary Test: T2 → T6/S8
```

> 正式な広告運用計画ではない。**App Store公開前のクリエイティブ検証用DRAFT**。
> 現在はTikTok・X・YouTube Shortsへの**オーガニック投稿のみ**で検証する。有料配信候補は、App Store公開後に「オーガニックで反応が良かった広告 × ストア遷移後のインストール率 × 初回プレイ率」で決める。

## 初回制作対象（この順に1本ずつ）

1. **T2「『交渉する』を英語で？」**（クイズ参加型・最軽量）
2. **T6/S8「英語アプリ、3日で消すよね」**（共感テキスト型）

第2弾候補: T10・S4（Daily Dash訴求）。
**初回から複数本同時制作はしない。** 1本投稿→反応と制作工程を確認→次へ。

## CTA運用ルール（公開前後で混在させない）

| フェーズ | 使用するCTA |
|---|---|
| App Store公開前（現在） | 「60秒だけやってみる」「無料・登録不要」「今日の問題に挑戦」 |
| App Store公開後 | 「無料でインストール」「今日から60秒」「App Storeで始める」 |

## 広告分類

### 獲得広告（目的: プレイ・LP遷移・ストア遷移・インストール）
T1, T2, T6, T10, S1, S4, S8 など。評価: CTR・遷移率・初回プレイ率。

### ブランド広告（目的: SpellDash・はちゃんの認知・保存・フォロー・指名検索）
T7, Y5, A2, A3, S5 など。
**はちゃん広告をCTRのみで評価しない。** キャラへの言及コメント・保存数・フォロー転換・再訪も確認する。

# ⑤ A/Bテスト案（オーガニック検証でも適用）

1. フック軸: 共感疲労型（T1/S1） vs クイズ参加型（T2/S4） vs 数字証拠型（T5/S3）
2. キャラ軸: はちゃん有り（S5/T7） vs 無し（S2/S8）※評価指標は分類ごとに変える（獲得=CTR、ブランド=保存/言及/フォロー）
3. CTA軸: 公開前3種の中で比較（「60秒だけやってみる」vs「無料・登録不要」vs「今日の問題に挑戦」）
4. 着地軸: トップ vs Daily直行
5. コピー軸: 機能型「思い出して打つから残る」 vs 情緒型「今日も、はちゃんと少しだけ。」

# ⑨ 必要素材

- **画面収録**: 60秒フルプレイ／テンポ良い正解連続15秒／ミス→答え→リベンジ／リザルト（ベスト更新）／ストリーク／Daily完走→グリッド／週間サマリー
- **画像**: はちゃん表情差分（既存2種＋キャラシートから追加候補5種）／高解像度スクショ／OG画像流用
- **音声**: 実機タイプ音／ゲーム内SFX／フリーBGM2曲（lo-fi・アップテンポ）／ナレーション（Y3のみ）
- **その他**: 商用可フォント（M PLUS Rounded等）／CapCut（無料）／UTM付きURL（計測は docs/SPEC_ACQUISITION.md 参照・**実装は未着手**）
