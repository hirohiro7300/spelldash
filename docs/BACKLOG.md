# SpellDash 改善バックログ（生きた文書）

> 2026-09-07 起草。創業者指示「改善案を無限に出して実装まで。方向がずれたら止める」に基づく自走用リスト。
> 実装済みは ✅、着手中は 🔧、未着手は ☐。**判断が要るもの・方針に触れるものは ⚠ を付け、実装前に創業者へ確認する。**

## 選び方（優先順位の軸）

1. **学べた実感**が増えるか（覚えた瞬間・語の粒度・正直な定義）
2. **明日また開く理由**になるか（終わりがある・積み上がる・自分のもの）
3. **10人ローンチ**の観察に効くか（初回体験・フィードバック導線・壊れない）
4. 実装コストが小さく、E2Eで守れるか
