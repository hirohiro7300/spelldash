# SpellDash 改善バックログ（生きた文書）

> 2026-09-07 起草。創業者指示「改善案を無限に出して実装まで。方向がずれたら止める」に基づく自走用リスト。
> 実装済みは ✅、着手中は 🔧、未着手は ☐。**判断が要るもの・方針に触れるものは ⚠ を付け、実装前に創業者へ確認する。**
> 禁止事項は据え置き: 決済／通貨／ガチャ／ショップ／通知／Battle改変／SQL実行と外部通知は創業者側。

## 選び方（優先順位の軸）

1. **学べた実感**が増えるか（覚えた瞬間・語の粒度・正直な定義）
2. **明日また開く理由**になるか（終わりがある・積み上がる・自分のもの）
3. **10人ローンチ**の観察に効くか（初回体験・フィードバック導線・壊れない）
4. 実装コストが小さく、E2Eで守れるか

| A4 | ✅ | **正解時にも発音**（設定・既定ON）: 自力で打てた瞬間に音で確認 | 綴り→音の結合。耳からの定着 |
| A5 | ✅ | **思い出せなかった語だけもう1周**: セット完了パネルに「思い出せなかったN語をもう一度」 | 終わりの直前に回収して「思い出せた！」で締める |
| A6 | ✅ | **初回の腕試し（10語診断）**: 初回だけ易→難の10語を出し、知ってた数で難易度を即決定（現在は12語観察後） | 社会人の初回体験が「apple/water」で終わらないように |
| A7 | ☐ | **リスニング出題**（Studyの切替）: 日本語の代わりに音声を聞いて打つ | 別モダリティで同じ語に触れる。定着の強化 |

| A10 | ✅ | **セット開始時の中身予告**: 「復習3・苦手2・新しい10」を開始メッセージで | 何をやるか分かってから始める |

| A14 | ☐ | **習得（10回）への道の可視化**: 覚えた単語帳の各語に「10日中 7日目」 | 覚えかけ→習得の距離 |
| A15 | ☐ | **同義語・派生語の一括復習**: 語根ファミリーを1セットで | Knowledge Map 予告 |
