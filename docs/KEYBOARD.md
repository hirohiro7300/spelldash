# SpellDash専用キーボード 設計メモ（2026-09-16 実装。仕様は docs/APP.md §4）

> 2026-07-16 創業者指示で構想のみ。**2026-09-16 アプリ化の決定に伴い実装**（`js/keyboard.js`）。以下は当初の設計メモ。

## 目的

- 日本語切替不要（OSキーボードのIME切替がスペル入力の最大の摩擦）
- 数字・記号・予測変換不要 → 誤タップ削減
- 入力速度向上とUX統一（端末・OSによらず同じ配列・同じ打鍵感）

## 構成

**A〜Z + Backspace のみ。** それ以外のキーは置かない。

## 設計案（アプリ化後の検討たたき台）

- 配列: QWERTY基本（物理キーボード学習との一貫性を優先。ABC配列は採用しない）
- キーは3段配列＋最下段中央にBackspace幅広キー。Shift/スペース/Enterは不要
  - 開始・答え表示・パスなどの操作は画面側ボタンが担う（キーボードは文字入力専任）
- 打鍵フィードバック: 既存WebAudio SEと統一、触覚（Haptics）はアプリ化後のネイティブAPIで
- 正解プレフィックスのハイライトと連動して、次に打つべきキーを薄く光らせる補助モード（オプション、デフォルトOFF: 学習の邪魔をしない）
- はちゃんは置かない（1画面1目的・入力領域は聖域）

## 実装解禁の条件

1. アプリ化（ネイティブ or Capacitor等）が決定している
2. PMF探索フェーズを抜け、スマホ体験のボトルネックが「OSキーボード」だと定性フィードバックで確認できている

## 現Webでの代替（実装済みの範囲）

- inputイベント照合によるソフトキーボード対応（予測変換・一括挿入対応）
- `autocapitalize="off" autocorrect="off" spellcheck="false"` などの入力属性調整

## 現Webのキーボードショートカット（実装済み・2026-09-07）

| キー | 動作 |
|---|---|
| Enter | 開始 ／ 分からない（答え表示）／ 答え表示後はスキップして次へ ／ 正解後の待ちの間は次へ。次の語が出てから 0.3 秒の Enter は、その語にまだ打っていなければ答えを開かない。待ちが終わって次の語が出たときは、前の語を打ち終えてから 1.2 秒の Enter も同じ（打ち終えたら Enter で次へ、の癖を次の語の「分からない」にしない） |
| Esc | Enter と同じ「分からない」（プレイ中のみ。正解後の待ちの間は何もしない） |
| Ctrl+.（Cmd+.） | 今の単語を発音 |
| Tab | 次の要素へ（正解後の待ちの間は効かない） |
| 💡 ヒント（ボタン） | 7秒迷うと表示。次の1文字を見る（×扱い） |

- Study の 60 秒（今日のセットの長さ「60秒」。docs/SPEC_MASTERY.md §4）のキーは Study と同じ（上の表のまま。答え表示の後は打ち直し）。時計はキーでは止まらない。終わりのパネルは見出しに焦点を置き、Tab で語チップとボタンを回る。

## 日本語の答え: 読みをローマ字で（2026-10-08）

- 日本語の答え（鎌倉幕府・ファシズム・X線 など。かな・漢字を含む答え）は、漢字に変換せず**読みをローマ字で打つ**（`js/romaji.js`、`body.romaji-answer`）。打ったかなの下に打ったキーを小さく出す（2 段）。1 打ずつ判定し、読みを打ち終えたら Enter なしで正解
- 入力欄は**読み取り専用**（`readonly`）にする。IME も OS キーボードも開かず、keydown だけが届く。IME が打鍵を取った形（`key` が `Process`）や JIS かな配列（`key` がかな）でも、物理キーの位置（`code` の `KeyA`〜`KeyZ`・`Digit`・`Minus`）でローマ字にする
- 画面キーボード: A〜Z に **ー**（長音。`-` として送る）を足す。ローマ字のカードでは常に出す（ー がある語だけに出すと答えの手がかりになる）。入力欄が読み取り専用なので、タッチ端末では設定が「オフ」でも盤面を出す
- ⌫ は受理済みの文字を消さない（英単語と同じ 1 ミス＝不正解）。空白・記号・Backspace は判定しない（ミスにもしない）
- 綴り: ヘボン式・訓令式の両方（shi/si, chi/ti, tsu/tu, fu/hu, ji/zi, sha/sya, cha/tya/cya, ja/zya/jya …）、小さいかなは x／l、っ は子音を重ねる（xtu も可）、ん は nn／n'／子音の前の n／語末の n。ー は -。ぢ・づ・を は di・du・wo のほか ji・zu・o でも通る
- どの読みでも打ち終えた時点で正解（Enter は要らない。長い読みの手前の読みで終わることもある）。打ち終えた直後に、終えた語の読みの続き（語末の ん の 2 つ目の n、長い読みの残り）として打ったキーは次の語の打鍵にしない。仕組みと時間は英単語と共通（次の節の「打ち越し防止」: 正解後の待ちの間は飲み、続きを打つ間は次の語を待たせる。次の語が出た後は、1 打を続きの見方と次の語の両方に食わせて、どちらかが拒んだ時点で解決する。Enter で自分から次へ進んだときは、次の語の 1 打目から受け付ける）。鑑真を n 1 つで終えた直後の n は、続き（2 つ目の n）としても 日米和親条約 の に の頭としても通る引き分けなので、次の語に に の n として見せたまま次の打鍵で決める: 続けて i が来れば に（次の語が受ける）、n が来れば nn は に に続かないので前の n を続きとして外し、いまの n を 1 打目にする（どちらもミスにならない）。語末の ん の 2 つ目の n は 1 打の続きなので、次の語を出す時刻を変えない（nn で終える人のテンポは n 1 つで終える人と同じ）
- かなの読み（accept のかな）が 1 つもないカード（自分で作った場面カードなど）は従来どおり入力欄に IME で打って Enter
- 読みの続きの持ち越し止めは、英単語の打ち越し防止（次の節）と同じ仕組み・同じ窓（`js/game.js` の `spill`・`SPILL_GAP_MS` = 600ms）

## 英単語: 出題語が別の正解の先頭部分のとき（2026-10-10、K0-1）

- **出題語を打ち切ったらその場で正解**（gym に対して gymnasium、a に対して an、sport に対して sports、photo に対して photograph が候補に残っていても止めない。`js/answers.js completedAnswer`）。以前は「まだ伸びる候補がある」として止め、Enter で答えが開いて×（思い出せず）になっていた（全パック有効で 170 枚）。出題語より短い別解（出題語 advertisement に対して ad・advert）は今までどおり、打ち切っても止めず、Enter で別解として受ける
- **Enter は「打った語で確定」**: 答えを見る前で、打った綴りがそのまま候補の 1 つに一致しているなら、出題語でも別解でもその語で確定する（出題語なら正解、別解なら「X も…この問題の語は Y」）。一致していなければ今までどおり答えを表示（×）。答えを見た後・全文入力・ローマ字の Enter は変えない
- **英語の打ち越し防止**（ローマ字の読みの続きと同じ仕組み。`js/game.js` の `spill`。記録は 1 つ）: 出題語で完成したとき、打った綴りより長い候補が残っていれば（a → an、gym → gymnasium、sport → sports）その続きの綴りを覚え、続きとして打ったキーは次の語の打鍵にしない。Study・Challenge・Daily とも。Shift など文字でないキーでは途切れさせない
  - **正解後の待ちの間**（Study。次の語はまだ無い）: 続きのキーは間が空いても続きとして飲む（このキーは次の語に入らない）。次の語を出す時刻 = max(本来の待ちの終わり, 続きの最後の打鍵 + 1.5 秒〔まだ続く。`SPILL_HOLD_MS`〕／+ 0.25 秒〔2 打以上で打ち切った。`SPILL_TAIL_MS`。続きの直後の余分な 1 打＝空白・gymnasiums の s を待ちの間に捨てる〕)。ただし次の語が全文入力（Enter で判定。a lot of などの句・計算カード）のときは待ちを縮めない（+ 0.25 秒の代わりに + 本来の待ちの長さ。全文入力は 1 打ずつ判定しないので、縮めると続きの直後の余分な 1 打が入力欄に入り「sa lot of」で Enter → ×になる。全文入力の語は稀でテンポへの影響は小さい。REVIEW-155 の 1）。0.25 秒で出したとき（続きの最後の打鍵 + 0.25 秒が本来の待ちの終わりより後だったとき＝待ちを縮めたとき）だけ、続きの最後の打鍵から min(本来の待ち〔覚えた の印・レベルアップの幕の 1.4 秒、チュートリアルの札の 1.5 秒を含む〕, 標準のペースの表の、語の種類の値〔英単語 0.7 秒・概念カード 0.9 秒。例文の有無によらない。長いペースでも同じ〕)までの次の語の 1 打目で、次の語が拒む字（続きの直後の空白・gymnasiums の s）はミスにせず捨てる（gym と打って空白を打つ人は本来の待ちの間に捨てられるのと同じ。例文の無い語が覚えた の印を取って 1.4 秒待つときも、守りの幅は表の値の 0.25 秒ではなく 0.7 秒・0.9 秒。REVIEW-155 の 3）。守りは**次の語が出た後の最初の打鍵で使い切る**（どの経路でも、字でも空白でも: 物理キー・画面キーボード・Android の input 経路〔値の a-z だけを判定するので空白は判定に入らないが、守りは使う〕・ローマ字〔空白は判定しないが、守りは使う〕。REVIEW-155 の 2）。1 打目だけ: 次の語が受ける字・2 打目から・この幅を過ぎた字は普通に判定。余分な 1 打（空白・s）がもう待ちの間に来て捨てていれば、守りは置かない（次の語が出た後の打ち間違いはミス）。続きを速く打ち切って次の語が本来の待ちの終わりに出たときは守らない（待ちは縮んでいない。gym とだけ打った人と同じく、次の語が出た後の字は普通に判定）。1 打で終わる続き（語末の ん の 2 つ目の n、an の n）は本来の待ちの終わりを変えない。続きを打たない人の待ちは変わらない。Enter で自分から次へ進んだら捨てる
  - **次の語が出た後**（`judgeKey`）: 1 打を「続きの見方」と「次の語」の両方に食わせ、どちらかが拒んだ時点で 1 回だけ解決する。続きだけが受ける → 続きとして飲む（1 打 0.9 秒の gymnasium の続き、an の n。次の語のミスにしない）。次の語だけが受ける → 次の語の打鍵（続きは終える）。両方が受ける（引き分け。a の直後の n と次の語 not／nine の n、in の直後の s・i と six の s・i）→ 次の語に入れて見せたまま（入力欄・typedPreview）記録し、次の打鍵で決める。次の語がその字で出題語として完成したら次の語の正解（in → inside の続きが次の語 side そのもの、another → another one の one）。両方が拒む → 普通のミス。ただし引き分けの字を外せばこの字が次の語の 1 打目として通るなら、外して 1 打目にする（an の n をあけて打ち、次の語 not を n から打つ。gym の後に n を打ちかけて止め、name を n から打つ。続きがまだ続くときも同じ）。引き分けの字を黙って外せないとき（下の「窓」の段の規則。窓の外で 2 字以上）は、打ち直しか打ち間違いかをその場では決めず保留する（**保留 restart**。その字は次の語に見せず、続きにも食わせない）: 次の打鍵で、保留の字 ＋ その字が次の語の頭から通れば打ち直しだった＝引き分けの字を外し、保留の字を 1 打目にする（gym の 0.8 秒後に n・a を打ちかけて止め、name を頭から打つ。ローマ字の いわじゅく の後の i・s → 遺跡 も同じ）。通らなければ次の語を打ち続けていた＝保留の字を打ち間違いとして数える（「違う」・1 ミス。in の後に six の s・i を打ってから x のつもりで s → 続けて x、または gym の後の n・a → m のつもりで n → e）。保留のまま 4 秒止まったら打ち間違い（in → s・i → s で止まると、4 秒後に「違う」。打ち直しと同じ打鍵の列なので待つが、黙って消さない）
  - **続きがまだ続くのに次の語がその字で完成する**（ngsl01 の out〔accept outside・outdoors〕の続き d・o と次の語 do）: その字では決めずに保留する（do を入力欄に見せるが受理しない）。次の打鍵が続き（outdoors の o）なら続きだった＝do を外して続きとして飲む（打っていない do に正解を付けず、残りの ors も次の次の語に流さない）。続きでないキーなら do の正解にして、そのキーは次の次の語の打鍵にする。打鍵が来なければ 1.5 秒（`SPILL_HOLD_MS`。Study の「続きを打っている間は次の語を出さない」と同じ長さ）で do の正解、Enter ならすぐ do で確定（打った語で確定）。1.5 秒の時間切れで do の正解にしたときは、続きの残り（ors）も続きとして飲む（1 打 1.5 秒より遅く outdoors を打つ人は do の正解になるが、残りの o・r・s は次の次の語の打鍵にしない。Study は待ちの間に飲み、続きを打つ間は次の語を待たせる。英単語だけ。ローマ字の読みでこの形の組は同梱データに無い）。同梱データではこの 1 組（マイ単語帳の場面カードでは作れる）
  - **別解としての完成**（hall〔accept hallway〕の続き way と次の語 manner の別解 way）: 続きが勝つ（別解は答えを見た扱いで自力にならないので、続きを打った人の次の語に付けない。manner は未入力のまま）。続きがまだ続くとき（hall〔accept hallways〕の続き ways の w・a を窓の外でゆっくり打ってから y）も同じで、保留せずにその字で続きと決めて引き分けの字を外す（y は次の語も受ける字なので打ち間違いにしない。4 秒止まっても×にしない）
  - 続きで次の語が完成した後（another one の one、保留の do）は、同じ語をもう一度なぞる打鍵を飲む（another one と打った人が、出題が one に変わったのを見て one をもう一度打っても、3 語目に流れない）
  - **窓**（最後の打鍵から 0.6 秒、`SPILL_GAP_MS`）と**窓の外**（4 秒まで、`SPILL_LATE_MS`。綴りを思い出しながらの 2〜3 秒の迷いも入る）の違いは、引き分けの字を次の語から外す（取り消す）ときだけ: 字が窓の中で打たれた・続きがすでに始まっていた（続きだけが受けた字がある。gymnasium の n・a を飲んだ後の s・i と次の語 six）・1 字（gymnasium の s と subject、iseki の i と 院政）・この字で続きを打ち切った のどれかなら黙って外す。それ以外（窓の外で 2 字以上、続きはまだ始まっていない。in のあと s・i をゆっくり打ってから d）は、その場では決めずに保留する（その字は続きにだけ食わせ、次の語には見せない）: 続きを打ち切れば（inside の e）全部が続きだった＝s・i を黙って外す（1 打 0.9 秒で inside・gymnasium を打つ人は次の語が×にならない）。続きが拒めば（six を打ち続けて x）次の語を打ち続けていた＝保留の字（d）を打ち間違いとして数える（「違う」。1 ミス＝不正解。正しく打った字を黙って消さない）。続きが拒んだ字が次の語の 1 打目として通るとき（gym の後の n・a・s → name を頭から打ち直す n）は、続きを打ちかけてやめたのかもしれないので保留 restart に切り替えて次の打鍵で決める（上の「両方が拒む」と同じ）。保留のまま 4 秒止まったら打ち間違い。Enter では保留の字は捨て、見せている字（si）で普通に判定する（答えが開く。ミスには数えない）。引き分けの字そのものは時間で消さない（見せている字を本人の操作なしに消さない）。4 秒を過ぎたら続きの見方だけ終え、次の語を 1 打目から打ち直せば外して 1 打目にする（窓の外で 2 字以上なら保留 restart を通る: 2 打目まで頭から通れば打ち直し）
  - 残り: 続きを打ち間違えた後（gymnaisum の i から先）は次の語の打鍵になる（docs/BACKLOG.md）
  - Enter: 引き分けの字は次の語に入っているものとして普通に判定する＝候補の 1 つに一致していればその語で確定（gym の後の nas と次の語 nasty の別解 nas）、そうでなければ答えを開く。保留（out の後の do）は保留の字で確定。Study で続きが終わった直後（続きの最後の打鍵から 1.2 秒、`ECHO_AFTER_DONE_MS`）の Enter は、窓の内外によらず「打ち終えたら Enter で次へ」の癖として、引き分けの字を外して 1 回だけ飲む（gymnasium の最後の m と次の語 moon、an の n と次の語 nine。答えは開かない）。2 回目の Enter は字が消えた状態で普通に判定する＝答えが開く（飲み続けて固まらない）。続きとして飲んだ後の Enter も同じで、Study の「打ち終えてから 1.2 秒の Enter は次の語の答えを開かない」守りを続きの最後の打鍵から数える。Challenge・Daily には Enter の守りが無い（以前から）
- 経路は 3 つとも同じ: 物理キーの keydown、画面キーボード（`#input` に keydown を合成）、Android の input イベント（`handleTextInput`。1 字ずつ値が伸びる Gboard でも、予測変換で gymnasium と一度に入っても、gym で完成して残りは捨てる。gymna まで一度に入って残りを 1 字ずつ打っても同じ）。input 経路は値の a-z しか見ないので、空白・ハイフンを含む続き（a → a large、rest → rest api）は続きの頭の a-z 以外を読み飛ばして比べる
- 次の語が全文入力（Enter で判定）のときは、英単語の続きを持ち越さない（全文入力は 1 打ずつ判定しない。物理キーだけ飲んで input 経路では飲まない、という食い違いを作らない。ローマ字の続きの扱いは以前のまま）。Challenge で続きが次の語を完成させた直後に出た 3 語目が全文入力のとき（another one の one・保留の do の次）も、完成した語をなぞる続きは作らない。保留の字で前の語を完成させたキー（out の後の do の保留中に 3 語目の頭の字）は 3 語目のものとして入力欄に入れる（物理キー・画面キーボード・input 経路とも。黙って消さない）。入れるのは打たれたとおりの字（物理キーは event.key、input 経路は入力欄に実際に入った字のうち受け付け済みの部分より後ろ。候補の確定・スワイプで 1 回に「In wh」と入っても、大文字も空白もそのまま。REVIEW-155 の 4）。Study で待ちを縮めるかどうかも、次の語が全文入力なら縮めない（上の「正解後の待ちの間」）
- 綴り違い・別解の案内への影響: 出題語の後ろに字を足す形の綴り違い（programme・maths・towards・dialogue・an など、全パック有効で打てるもの 43 組）は出題語の所で正解になり、「X も正解（この教材では Y）」の行は出ない（記録は以前と同じ自力の正解）。出題語で始まる長い別解（gymnasium など 155 組）は、以前の「別解の案内（×なし・自力にならない）」ではなく出題語の自力の正解になる
