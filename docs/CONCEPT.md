# SpellDash デザインコンセプト「墨と朱（Ink & Signal）」

> 2026-09-21 起草。創業者指示「AI感をなくしてサービスとして見栄えをよくする／不要な機能は消す／継続のためのシンプルさ／音声の改良／コンセプトを作ってサイト全体をカッコよく」に基づく。
> docs/DESIGN.md の方向（Monkeytype / Notion / Obsidian 系のミニマル、大人がカフェで開ける見た目、ゲーム性は裏で回す）を、具体的な見た目の規則に落としたもの。実装の単一の基準は `css/tokens.css`。

## 1. ひとことで

**大人の練習帳。** 紙と墨、アクセントは朱だけ。英語は等幅で打つ。飾らない。

SpellDash は「思い出して打つ」道具。画面は道具らしく静かで、注意を英単語と入力欄に集める。カラフルな報酬・絵文字・グラデーションで盛り上げない。積み上がった記録が、静かに残っていく。

## 2. 原則（迷ったらこれ）

1. **紙と墨、朱は1点だけ。** 背景は紙（オフホワイト）、文字は墨。色は朱（signal）1色をいちばん大事な1か所（スタート、いま打っている文字）にだけ使う。ダークは反転（墨の紙に、紙色の文字）。
2. **英語は等幅。** 打つ対象＝英語は IBM Plex Mono。日本語 UI はシステムのゴシック。等幅が「タイピングの道具」であることを一目で伝える。
3. **罫線で区切る。影で浮かせない。** グラデーション・ドロップシャドウ・光彩・バッジの装飾は使わない。1px の罫線と余白で構造を作る。角丸は小さく（6px、カードは 10px）。
4. **1画面1目的。** 数字は1行、説明は1文。見出しは1つ。ホームは「いまの道 → スタート」だけが目に入ればよい。
5. **絵文字は UI に使わない。** ボタン・ラベル・見出し・チップから絵文字を外す（お知らせの本文、はちゃんのセリフ、ユーザーが書いたメモは可）。アイコンが要る所は 16px の線画 SVG（`js/icons.js`）を1色で。
6. **動きは短く静か。** 120〜200ms のフェード／位置移動だけ。点滅・バウンス・虹色・紙吹雪はしない。`prefers-reduced-motion` では動かさない。
7. **打った文字は朱、未入力は薄墨。** 虹色の文字をやめる。進みは2トーンで十分に分かる。答えの表示も同じ2トーン。
8. **はちゃんは小さく、3場面だけ。** 枠は罫線、吹き出しは紙色。主役にしない（docs/CHARACTER.md）。
9. **数字を誇張しない。** XP・レベル・コンボ・速度は小さな文字で1行に。目立つのは「覚えた語数」と「今日のセットの残り」だけ。
10. **文言は短く、断定で。** 「〜しましょう！」「✨」「すごい！」を避ける。事実と次の一手だけ書く（例: 「今日のセット 残り6語」）。

- 余白は 4 の倍数（4 / 8 / 12 / 16 / 24 / 32）。

## 4. 部品の規則

| 部品 | 規則 |
|---|---|
| ボタン（主） | 墨の塗り＋紙色の文字（ダークは反転）。高さ 40px、角丸 6px、太字 14px。ページに1つ |
| ボタン（朱） | スタート／続きから だけ。朱の塗り＋白文字 |
| ボタン（副） | 1px `--line-2` の枠、透明地、墨の文字。ホバーで `--paper-3` |
| チップ | `--paper-3` の面、角丸 999px、12px、影なし。状態色は文字色だけで表す |
| カード | `--paper-2`、1px `--line`、角丸 10px、内側 16〜20px。影なし。見出しカードもグラデーションにしない |
| 入力欄 | `--paper-2`、1px `--line-2`、フォーカスで朱の枠＋`--focus`。文字は等幅 20px |
| 道 | 1本の細い縦線（`--line-2`）。済み＝墨の輪郭に✓、現在地＝朱の円に「スタート」、未着手＝`--line-2` の点。ラベルは墨、補助は `--ink-3` |
| ヘッダー | 紙色、下に 1px 罫線、ロゴは等幅の「SpellDash」ワードマーク（アイコンは黒地に白の SD 1文字、角丸 6px） |
| 見出し | 20〜28px、太さ 700、字間 -0.01em。装飾なし |
| リンク | 墨の下線。ホバーで朱 |
| はちゃん | 32px の丸アイコン＋紙色の吹き出し（1px 罫線）。3場面のみ |

## 5. やめること（AI感の源）

- 青→紫のグラデーションの見出しカード、光る影、ピル型のカラフルなバッジ
- UI ラベルの絵文字（🔥 📖 ✨ 🎉 🏆 📝 🔊 💡 ⚡ 🎯 など）
- 虹色の文字（js/colors.js の文字ごとの固定色）
- 「✨ 覚え方を作る」「がんばろー！」のような盛り上げ文言
- ホームの数字の羅列（連続日数・レベル・週の目標・ミッション・週間レポートが一度に見える状態）
- 同じ情報の重複（今日のセットとミッション、正解数と今日思い出せた数 など）

## 6. 残すこと

- 学習の中身（思い出して打つ、答え表示、例文、復習の仕組み、道、コース、続きから）
- 記録（覚えた語、カレンダー、週間レポート＝学習データの中で）
- はちゃんの3場面（ホームの一言・セット完了・ランクアップ）— ただし小さく
- Battle（触らない）

## 7. 音

- 発音: 端末にある最も自然な英語音声を自動で選ぶ（Microsoft *Natural* → Google US/UK English → Apple Enhanced/Premium → その他）。プロフィールで声を選んで試聴できる。速さは 0.95、例文はやや遅く。
- 効果音: 短く・小さく・少なく。正解はごく短いクリック音、思い出せずは低い1音。Challenge の BGM は残すが既定は控えめ。

## 8. 実装の進め方

1. `css/tokens.css` を全ページの最初に読み込み、既存の CSS を段階的にトークンへ置換する（色・角丸・影・フォント）。
2. 絵文字ラベルを文言または `js/icons.js` の SVG に置換。
3. 虹色（js/colors.js）を2トーンに。
4. ホームの情報を削る（docs/BACKLOG.md の「Batch 27 整理」）。
5. 各ページを部品の規則に合わせる。E2E のセレクタ（id・class）は変えない。
6. スクリーンショットで 390px／1000px、ライト／ダークを確認。
