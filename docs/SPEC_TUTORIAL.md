# SPEC: チュートリアル（初回の 1 セットに 1 文ずつ添える）

> 2026-10-05 起草（創業者「チュートリアルも作ろう」）。実装は Batch 44。原則は docs/CONCEPT.md、はちゃんの登場は docs/CHARACTER.md の 3 場面のまま（チュートリアルには出さない）。

## 1. ねらい

初めての人が、説明を読まずに **「見て → 思い出して → 打つ」「分からなければ Enter」「復習は自動」** を 1 セット目の中で身につける。
スライド式の案内（読んでから始める）はやらない。**実際の操作の直後に 1 文**だけ添え、次の操作で消える。トップページの「使い方 3 項目」と腕試しの注記は今のまま（読む人のため）。

## 2. 出すところ（3 ステップ・各 1 文・順番は固定）

> Batch 45 の初回点検で、6 ステップのうち画面の他の文と同じことを言っていた 3 つ（1 語目「日本語を見て、英単語を打つ。」、完了「明日の復習は自動で出る。」、連続日数）を削った。札は **画面のどこにも書いていない「いま起きたことの意味」** だけを言う。操作の案内は #word（「分からないときは Enter で答えを表示」）と #message（結果）が持つ。

| # | きっかけ | 文 | 消えるとき |
|---|---|---|---|
| T2 | 初めて Enter で答えを見た（打ち間違いで答えが出た時も） | この語は数問後にもう一度出る。 | 次の語へ進んだ |
| T3 | 初めて自力で正解した | この語は、次は日をあけて出る。 | 次の語へ進んだ（最長 5 秒）。T3 を出した語は、次の語まで 1.5 秒置く（札の「この語」が次の語を指さないように）。Enter で先へ進んだときも次の語で消す。Challenge・Daily は待ちが無いので、出してから 1.5 秒たった後の語で消す |
| T4 | 1 セット目のあと、道に戻った | 毎日、スタートを押すだけ。約5分。 | 「わかった」／スタートを押した |

- T2・T3 は腕試しの中で起きる（10 語の中で Enter も自力正解もほぼ必ず起きる）。起きなければ次のセットで出す
- 1 画面に出るのは常に 1 つ。文は 20 字以内（390 で 1 行）
- 既に学習記録のある人（stats が空でない、または腕試し済み）には出さない＝既存ユーザーには一切変化なし
- 文は 1 つの定数表（js/tutorial.js の `STEPS`）。「！」なし、常体
- 札と重ならないよう、初回の画面から消したもの（Batch 45）: 開始時の「腕試し 10語。知らない語は Enter」、完了パネルの「明日の復習 N語」のセル（「明日の復習: …」の行が持つ）、初日の「1日連続」の返事、腕試し中のレベルアップの演出と「今日のセット 0 / 15」のバー、腕試しの注記の「約2分」（実測は約5分）

## 3. 部品 `.coach`

- **画面下の 1 本の札**（position: fixed、中央、最大 480px）。対象要素の脇には置かない: 入力欄・答え・道のどれも隠さず、出題ごとにレイアウトが動かない。画面キーボード表示中は `body.osk-open` でキーボードの上に出る
- 面 `--paper-2`、1px `--line-2`、角丸 10、文字 13px `--ink`。札自体は `pointer-events: none`（押せるのは「わかった」だけ）
- 吹き出しの三角・影・アニメーションは無し（`prefers-reduced-motion` に関係なく静止）。出入りは opacity の 150ms だけ
- 右端に「わかった」の文字ボタン（T4〜T6 だけ。T1〜T3 は操作で消えるので無し）。Esc でも閉じる
- `role="status" aria-live="polite"`。**フォーカスは奪わない**（打っている最中なので）。閉じるボタンに Tab で届く
- はちゃんの顔・名前は出さない（CHARACTER.md の 3 場面を増やさない）
- 4 テーマ（light／dark／paper／indigo）でトークンだけで描く

## 4. 状態

- `localStorage.spelldash_tutorial` = `{ "seen": ["T2","T3","T4"], "started": true }`
- 初期化時: 腕試し済み、または word_stats が 1 件以上 → `seen` を全部埋める（既存ユーザー除外）
- 設定ページ「学習」節に「チュートリアルをもう一度」（文字リンク）。押すと `seen` を空にし、次のセットから T2・T3、道に戻ったとき T4 を出す
- ログイン同期の対象外（端末ごと）

## 5. 実装

- 新規 `js/tutorial.js`（`initTutorial()` を main.js から呼ぶ。index.html だけ）。きっかけは既存イベント `spelldash:game-start`／`spelldash:word`／`spelldash:session-end`／`spelldash:game-end` と、game.js に 2 行だけ足す `spelldash:reveal`（答え表示）・`spelldash:recall`（自力正解）、main.js の「道に戻る」が投げる `spelldash:home`（道が見えた）
- CSS は `css/brand.css` に「coach」節（全ページ共通部品として。使うのは index だけ）
- 文言は tutorial.js の `STEPS` に集約（E2E が参照する）
- E2E: 初回の流れで T2→T3→T4 が順に 1 つずつ出ること、1 語目と完了パネルでは出ないこと、2 回目の訪問では出ないこと、設定の「もう一度」で T2 が戻ること、既存ユーザーの seed では一切出ないこと

## 6. やらないこと

- モーダルのスライド、暗幕で画面を止める案内、ハイライトの穴あき（1 画面 1 目的に反する）
- Battle／Challenge／学習データ／単語帳のチュートリアル（主線が分かれば他は見れば分かる。必要なら 10 人ローンチの観察後に）
- はちゃんに説明させること
