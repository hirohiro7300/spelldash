# スラング（Batch 80）

創業者の決定（2026-11-04）: スラングを覚える機能を入れる。形は「独立したスラングの学習」（ホームに 3 つ目の入口・スラングだけの回と数）。中身は日常会話のくだけた表現・仕事のチャットと略語・ネットのくだけた表現の 3 つ。失礼な語・性的な語・差別語は入れない。

## 1. 入口と画面

- ホーム: 「マイ単語帳」の下に 3 つ目のボタン「スラング」（`/slang.html`。マイ単語帳と同じ控えめな板）。ナビは「ホーム・英単語を学ぶ・学習状況・設定」の 4 つのまま。
- 学習状況: マイ単語帳の 1 行のすぐ下に「スラング N語・覚えた M」（スラングの画面へのリンク）。2,858 語の数とランクとは別の行。
- スラングの画面（`slang.html`・`js/slangPage.js`。ヘッダー・ナビ・フッターはほかのページと同じ。noindex・sitemap に載せない）:
  - 数（選んだグループの範囲の N語・これから・あやふや・覚えた）と「学ぶ」（`/?learn=slang`。絞ると `&group=…`）
  - 絞り込み「すべて・日常会話・仕事・ネット」（押したボタンが `aria-pressed`。URL の `?group=` に残し、開き直しと回の終わりの「スラングへ」で同じ形）
  - 一覧: 英語・状態・意味・使い方の 1 行・例文と訳。組み込みの一覧なので足す・消すは無い。

## 2. 中身（`js/slangData.js`）

- 150 項目: 日常会話 52・仕事のチャット・略語 51・ネット 47。1 項目は id（`slang-<綴り>`。状態の鍵なので変えない）・グループ・英語（画面の形）・意味（40 字まで）・使い方の 1 行（誰と・どこで。例: 親しい相手だけ・仕事のチャットで可）・短い例文と訳。略語に `abbr`、例文の中の形が違うときは `exForm`。
- 英語はマイ単語帳と同じ字だけ（英字・数字・ハイフン・アポストロフィ・語の間の空白 1 つ・40 字まで。`js/myWordsCore.js checkEnText`）。略語は広く使われる 1 つの意味で書く。
- 入れない: 失礼な語・性的な語・差別の語・薬物と酒・暴力・商品やサービスの名前。主な意味が不快な語は、軽い意味があっても入れない。単体の検査が入れてはいけない語の一覧（ハッシュで持つ）と照らす。

## 3. 打ち方と 3 状態

- 打ち方はマイ単語帳と同じ: 英小文字だけの語は 1 字ずつ、熟語・ハイフン・アポストロフィ・略語（FYI・lol など）は全文入力 + Enter（大文字小文字・空白・ハイフン・アポストロフィを見ない。FYI は fyi でよい）。
- 3 状態（これから・あやふや・覚えた）の決まりは公開の語と同じ（`js/learnState.js applyLearnAnswer`）。
- 置き場は人ごとの鍵 `spelldash_slang` 1 つ（`{ "<id>": { ls, lsd?, lsAt } }`。項目ごとの状態だけで、一覧そのものは持たない）。読めない値は上書きしない。一覧から外れた id の状態も消さない（数えない）。
- 書かない物: 語の記録（`spelldash_word_stats`）と送る 15 列（スラングの回は出題の記録 recordPlay を呼ばないので、後の書き手も書かない）・公開の語の 3 状態・6 つの数・ランク・最高到達ランク・マイ単語帳の鍵・中心の学習の回の続き（`spelldash_learn_session`）。

## 4. 学ぶ回（`/?learn=slang`）

- マイ単語帳の学ぶ回の機械をそのまま使う（`js/game.js` の材料 `src`: マイ単語帳は `MY_SOURCE`、スラングは `js/slang.js slangLearnSource`）。柱は「スラング」。出題は意味、ヒントで意味と使い方の 1 行、答えの後に使い方と例文。
- 列は これから（一覧の順）→ あやふや → 覚えた（最後に答えた時刻の古い順）。1 回 10 語。`&group=` のときはそのグループだけ。
- 回の終わり: 「N語 終わり」・今回 覚えた／あやふや・「スラング（仕事） 覚えた M / N」・「続けて学ぶ」・「スラングへ」。
- 学んだ日・XP: マイ単語帳（Batch 79）と同じく、中心の学習と同じに黙って数える（連続日数・カレンダーの学んだ日・XP には入る。ランク・3 状態の数・学習状況の 6 つの数には入らない）。

## 5. 人ごとの領域・バックアップ・同期

- `spelldash_slang` は人の記録の鍵（`js/areaGuard.js` の端末の鍵の一覧に無い鍵はみな人ごと。`scripts/test-areas.mjs` の人の記録の鍵の一覧に足した）。ゲスト → A の「はい」で移り（スラングだけを学んだゲストにも「移す？」を聞く: `js/areaSwitch.js hasRecords`）、A と B は別々、バックアップの書き出しと読み込みに入り、開き直しても残る。
- クラウドへの同期はしない（表を作らない）。別の端末へはバックアップで移す。
