# 分野パック（場面カード集）のデータ形式

ニッチな業務領域の用語を「場面（意味）→ 用語」の場面カードで学べるようにするための教材単位。
`data/packs/<packId>.json` に1ファイル1パック。ユーザーは「単語帳」ページの教材ライブラリで追加すると、
ホームのカテゴリに現れて Study／Challenge で出題される（追加しない限り読み込まれない）。

## ファイル

```json
{
  "subject": "english",
  "category": "<packId>",
  "label": "不動産 実務",
  "blurb": "賃貸・売買の現場で毎日出る用語。契約・重説・ローン・管理まで",
  "audience": "不動産会社の新人、宅建の勉強を始めた人",
  "genres": { "re-rent": "賃貸の流れ", "re-sale": "売買の流れ", "re-law": "法律・重説" },
  "words": [ ...カード ]
}
```

- `category` は `manifest.json` の id と一致させる。英小文字（例: `realestate`）
- `genres` は `tags[0]` → 表示名。パック内で使う全ジャンルを載せる（未登録のタグは検証で NG）
- `blurb` は40字以内、`audience` は30字以内（ライブラリのカードに出る）

## カード（1枚）

```json
{
  "id": "concept-re-jusetsu",
  "en": "re-jusetsu",
  "kind": "concept",
  "answer": "重要事項説明",
  "accept": ["重説", "重要事項の説明"],
  "ja": "契約前に宅建士が物件と取引条件を説明する手続き",
  "q": "契約の前に、宅地建物取引士が物件の権利関係や設備、取引条件を書面で説明する。買主・借主が納得してから判を押すための手続き",
  "explain": "宅建士の記名と説明が必要。契約書（37条書面）とは別の書類",
  "level": "easy",
  "tags": ["re-law"],
  "say": "important matters explanation"
}
```

| 項目 | ルール |
|---|---|
| `id` | `concept-<en>` に一致 |
| `en` | `<パック接頭辞>-<英字キー>`。英小文字・数字・ハイフンのみ。**他パックと衝突しないよう必ずパック固有の接頭辞**（例: `re-`, `acc-`, `hr-`） |
| `kind` | `"concept"` 固定 |
| `answer` | 打つ答え。日本語の用語・略語（大文字）・英単語（小文字）。40字以内。**q の中に answer の文字列を入れない** |
| `accept` | 別解 0〜6個。略称・正式名称・カタカナ・英語表記・よくある表記ゆれ。判定は NFKC 正規化＋小文字化で比較されるので、大小文字違いは不要 |
| `ja` | 意味の要約（30字前後）。一覧と答え表示に出る |
| `q` | 場面・意味の説明。30〜120字。「誰が・いつ・何をする場面か」が分かる具体的な文。答えが推測できる手がかりは入れるが、答えそのものは書かない |
| `explain` | 答えの後に出る1行の補足（80字以内）。定義の言い換えではなく「現場で効く一言」（混同しやすい語、なぜ重要か、式、数字の目安） |
| `level` | `easy`（その業界で最初に覚える語）／`normal`（1年目に出る）／`hard`（経験者・資格レベル）。目安は 4:4:2 |
| `tags` | `[ジャンル, ...]`。先頭がジャンル（`genres` に登録）。略語なら `"abbr"` を2つ目に |
| `say` | 発音に使う英語（略語の正式名称や英訳）。英語が無い用語なら省略 |

## 内容の方針

- 1パック 40〜60枚、ジャンル 4〜8個。業界の「共通言語」を一通り、入門から順に
- 正確さ最優先。年ごとに変わる数字（税率・保険料率・上限額）は書かない。書くなら「目安」と明記
- 差別・断定・法的助言に読める表現は避ける
- 同じ answer をパック内で重複させない。他パックとの重複は可（別 id なので統計は別）

## 検証

```bash
node scripts/validate-words.mjs   # data/english と data/packs をまとめて検証
```

- 形式・重複・`genres` の網羅・`manifest.json` の `count` との一致を確認する

## レベル別パック（英検・TOEIC）: 英単語形式

試験のレベルごとに英単語（en → ja）を集めたパック。場面カードではなく、通常の英単語カードと同じ「日本語を見て英単語を打つ」出題になる。
ファイルに `"cardType": "word"` を付ける。追加した人だけに出るのは分野パックと同じで、「すべて」や Daily Dash には混ざらない。

```json
{
  "subject": "english",
  "category": "eiken2",
  "cardType": "word",
  "label": "英検2級",
  "blurb": "高校卒業レベル。長文と英作文で頻出の1,200語のうち核になる語",
  "audience": "英検2級を受ける高校生・社会人",
  "genres": { "society": "社会", "science": "科学", "emotion": "感情", "action": "動作", "work": "仕事" },
  "words": [
    { "id": "english-negotiate", "en": "negotiate", "ja": "交渉する", "pos": "動", "level": "normal", "tags": ["work"] }
  ]
}
```

| 項目 | ルール |
|---|---|
| `id` | `english-<en>`（他カテゴリに同じ語があれば同じ id になり、学習記録を共有する。それでよい） |
| `en` | 英小文字とハイフンのみ。句・熟語は入れない（1語） |
| `ja` | 最も代表的な訳を1つ（必要なら2つを「・」で）。24字以内。試験でその語が問われる意味を優先 |
| `pos` | 品詞: `名` `動` `形` `副` `前` `接` `代` `助` `間`。2品詞なら主な方 |
| `level` | パック内の相対難易度。そのレベルの中で頻出・基本＝`easy`、標準＝`normal`、上位＝`hard`。目安 3:4:3 |
| `tags` | 先頭がジャンル（意味分野）。`genres` に登録 |

- 1パック 110〜130語。同じパック内で重複させない。同じ試験の下位レベルに入れた語は上位に入れない（試験内で一貫させる）
- 「そのレベルで新たに覚える語」を選ぶ。全レベル共通の超基本語（the, is …）は入れない
- 級・スコア帯と語彙の対応は公式の語彙表が無いので「目安」。検定団体名や商標的な表現は label 以外で使わない

## 文法パック: 穴埋め形式

英文の空欄に入る語を英語で打つ。場面カードと同じ仕組み（`kind: "concept"`）で、`q` が「空欄つきの英文＋日本語訳」、`answer` が空欄に入る語。
ファイルに `"cardType": "grammar"` を付ける（出題ラベルが「空欄に入る英語を打つ」になり、発音は `say` の全文を読む）。

```json
{
  "subject": "english",
  "category": "grammar-jhs3",
  "cardType": "grammar",
  "label": "中学英文法 3年",
  "blurb": "現在完了・関係代名詞・分詞・間接疑問。高校入試で差がつく文法",
  "audience": "中学3年生、中学文法をやり直す社会人",
  "genres": { "g3-perfect": "現在完了", "g3-relative": "関係代名詞" },
  "words": [
    {
      "id": "concept-g3-perfect-been-to",
      "en": "g3-perfect-been-to",
      "kind": "concept",
      "answer": "have been",
      "accept": ["'ve been"],
      "ja": "現在完了（経験）",
      "q": "I ____ to Kyoto twice.（私は京都に2回行ったことがあります）",
      "explain": "「行ったことがある」は have been to。have gone to は「行ってしまって今いない」",
      "say": "I have been to Kyoto twice.",
      "level": "easy",
      "tags": ["g3-perfect"]
    }
  ]
}
```

| 項目 | ルール |
|---|---|
| `q` | 英文（空欄は半角アンダースコア4つ `____` を**ちょうど1か所**）＋全角カッコで日本語訳。訳と文脈から答えが1つに決まるように書く |
| `answer` | 空欄に入る語（1〜3語、小文字。文頭でも小文字。`I` だけ大文字）。判定は大小文字・空白を無視するので、表記ゆれは気にしなくてよい |
| `accept` | 短縮形（`'ve been`）や、文法的に同じく正しい別の埋め方。別解が多い問題は避けて文を直す |
| `ja` | 文法項目名（例: 現在完了（経験）、比較級、関係代名詞 which）。20字以内 |
| `explain` | なぜその形になるかの1行（90字以内）。よくある誤り・混同しやすい形に触れる |
| `say` | 空欄を埋めた完成文（英語のみ）。発音に使う。必須 |
| `tags` | 先頭が文法項目のジャンル（パック接頭辞つき）。`genres` に登録 |

- 1パック 60〜80枚。同じ文法項目に「基本形→疑問文・否定文→応用」の順で複数枚
- 空欄の語は英文の他の場所に現れないようにする（検証で弾かれる）
- 学習指導要領の区分は目安。学年の境目にある項目は、より一般的な扱いに寄せる

## 英作文パック: 英文を丸ごと打つ

日本語の文を見て、英文を丸ごと打つ。語順・時制・冠詞まで含めて判定するので、文法の「運用」の練習になる。場面カードと同じ仕組み（`kind: "concept"`）で、`q` が日本語文、`answer` が英文。
ファイルに `"cardType": "writing"` を付ける（出題ラベルが「日本語を英文にして打つ（項目）」になり、ヒントは1語ずつ、発音は `say`）。`"wordBank": true` を付けると、答えの語をシャッフルして問題文の下に見せる**並べ替え**形式になる（ラベル「語を並べ替えて英文を打つ」）。

```json
{
  "subject": "english",
  "category": "writing-jhs",
  "cardType": "writing",
  "wordBank": false,
  "label": "中学英作文",
  "blurb": "中学で習う文法で言える日常の文を、日本語から英文にして打つ",
  "audience": "中学生、中学英語をやり直す人",
  "genres": { "wj-perfect": "現在完了", "wj-relative": "関係代名詞" },
  "words": [
    {
      "id": "concept-wj-perfect-been-to",
      "en": "wj-perfect-been-to",
      "kind": "concept",
      "answer": "I have been to Kyoto twice.",
      "accept": ["I've been to Kyoto twice."],
      "ja": "現在完了（経験）",
      "q": "私は京都に2回行ったことがあります。",
      "explain": "「行ったことがある」は have been to。have gone to は「行ってしまって今いない」。回数は文末",
      "say": "I have been to Kyoto twice.",
      "level": "easy",
      "tags": ["wj-perfect"]
    }
  ]
}
```

| 項目 | ルール |
|---|---|
| `q` | 自然な日本語の文（15〜45字）。訳が複数あり得るときは全角カッコで指定語を添える: 「私は昨日その本を読み終えました。（finish を使って）」 |
| `answer` | 英文（2〜12語、通常の大文字・句読点）。判定は大小文字・空白・句読点・アポストロフィを無視するので、`Im` と `I'm` は同じ扱い。語順が違えば不正解 |
| `accept` | 同じ意味で同じ文法項目を使う別解（短縮形 `I've`／`I have` の両方、`will`／`be going to` が両方自然な場合など）。別解が3つを超える文は避けて q を絞る |
| `ja` | 文法項目名または場面（20字以内） |
| `explain` | 語順・時制・冠詞のポイントと、日本人がよくする誤りを1行（90字以内） |
| `say` | 英文（answer と同じ）。必須 |
| `tags` | 先頭が項目のジャンル（パック接頭辞つき）。`genres` に登録 |

- 1パック 60〜100枚。同じ項目で「肯定→疑問・否定→応用」の順に複数枚
- 固有名詞は Kyoto・Tokyo・Ken・Emi など教科書に出る範囲。数字は英単語で（two, not 2）
- 並べ替え（`wordBank: true`）は語の順だけが問題なので、10語以内の文にする

## 義務教育パック（社会・理科・国語・数学）: 日本語で答える場面カード

中学・小学の暗記項目を「説明 → 用語・人名・地名・年代」で答える。仕組みは場面カード（`kind: "concept"`）と同じで、答えは日本語。
ファイルに `"cardType": "school"` を付ける（出題ラベルが「説明に合う語を答える」になる）。

```json
{
  "id": "concept-jh1-yoritomo",
  "en": "jh1-yoritomo",
  "kind": "concept",
  "answer": "源頼朝",
  "accept": ["みなもとのよりとも", "頼朝"],
  "ja": "鎌倉幕府を開いた初代将軍",
  "q": "平氏を滅ぼしたあと、1192年に征夷大将軍に任じられ、鎌倉に武家政権を開いた人物",
  "explain": "弟の義経は平氏を滅ぼした立役者だが、対立して追われた。「いい国（1192）つくろう」は将軍任命の年",
  "level": "easy",
  "tags": ["jh1-kamakura"]
}
```

| 項目 | ルール |
|---|---|
| `answer` | 教科書の標準表記（漢字）。年代を問う場合は「1192年」のように数字＋年 |
| `accept` | **ひらがなの読みを必ず入れる**（かな入力で正解できるように）。略称・別表記・旧称も。年代なら「1192」も |
| `q` | 教科書の説明に沿った具体的な文。答えの語は入れない。年代・地名など手がかりを1つ以上入れて答えが1つに決まるように |
| `ja` | 一言の要約（20字前後） |
| `explain` | 覚え方・関連事項・混同しやすいものを1行（90字以内）。語呂合わせ可 |
| `level` | その学年の中での基本／標準／発展 |

- 学習指導要領・検定教科書で標準的に扱う内容だけ。学説が分かれる年代（鎌倉幕府の成立年など）は、q の中で「征夷大将軍に任じられた年」のように問い方を限定する
- 現在も変わりうる統計（人口・生産量の順位）は「〜年時点」を書かないと使えないので避けるか、順位が安定しているものだけ
- 漢字の読みを問うパックは answer をひらがなにする（accept は不要）
- **問題文に読みが書いてあるカード**（同音異義語の書き分け「同じ音『たいしょう』の…」、漢文の句法「『いまだ〜ず』と読み…」など）は `"kanjiOnly": true` を付け、accept に読みを入れない。出題ラベルが「漢字で答える」に変わる。読みが q に書いてあるのに accept にもあると、q を写すだけで正解できてしまう（検証: accept の語が q に含まれていたら NG）
