# E2E の分け方（Batch 78）

tests/e2e.mjs の節（全 74 節）を、英単語の学習に絞った形（Batch 78）に合わせて 3 つに分けた一覧。分けた先は scripts/e2e-shard.mjs の `HOLD`（保留の節と理由）が持つ。

- **残す**（38 節）: 商品の仕様として CI で流す。
- **内部検査**（8 節）: 利用者の面ではない仕組み（計測・書き手・配信では転送と入口の門でホームへ移すページのコード）を CI で流す。決まりは単体の検査でも守る。
- **保留**（28 節）: CI で流さない。コードは消さない。scripts/e2e-shard.mjs の `--held` で流せる。

## 保留にしてよい条件

保留にしたのは次のどちらかだけ。「Batch 78 で落ちたから」だけでは保留にしない（落ちた節は検査を直して CI に残した）。

1. 英単語の学習に絞った形で、利用者がその面に届かない節（ホームに出さない・古い URL はホームへ案内する）。その節が守っていた仕様のうち今も製品に効く分は、「代わりに何が仕様を守るか」に名前を挙げた検査が CI で守る。
2. 検査が 0 件の目印の節。

中心の学習・3 つの状態・移行・保存・アカウント・ランク・簡素化した導線の検査は CI から外さない。

## 流し方

scripts/e2e-shard.mjs に次の引数を付けて流す。

- CI の 4 組: `--shard k/4`（保留の節は入らない）
- 保留の節だけ: `--held`
- 1 節だけ: `--only "<節の名前>"`
- 節を CI に戻す: scripts/e2e-shard.mjs の `HOLD` からその行を消す。`--check 4` が、どの節もちょうど 1 つの組か保留のどちらかにあることを確かめる。

「旗を外したページ」は、js/focus.js の `FOCUS_ENGLISH` を外した前の形のページ。前の形にしか無い入口から同じ書き手や判定を動かす塊は、その塊だけ旗を外したページで流す（コードは同じ）。

Battle・タイピング練習・タイピングゲームの 3 ページは、旗のある配信ではページの入口の門（`<head>` の頭の `<script id="focusGate">`）で英単語のホームへ移る（Batch 78 段 7）。3 ページを直接開いて中身を見る塊（Battle・タイピングが学習の記録を変えない: 受け入れ 6 など）は、3 ページだけ旗を外したページ（`newPageGateOff`。検査の台が 3 ページの `<html data-focus>` を外して返す。ほかのページは旗のまま）で流す。前の形のページ（`newPageFlagOff`）も 3 ページの門を外す。
